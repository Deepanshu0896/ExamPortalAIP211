Course Code: CS201 Course Title: Web Development L-T-P: 3-0-2 Credits: 4 Semester: Autumn / Spring

CS201: Web Development — Course Syllabus

Unit Core Curriculum Topics & Learning Modules
Unit I Web Architecture & Client-Side HTML5 Markup Internet protocols and client-server architecture, HTTP/HTTPS request-response lifecycle, HTML5 semantic structure (<header>, <nav>, <main>, <article>, <aside>, <footer>), advanced tables with cell spans (rowspan, colspan), interactive accessible web forms, HTTP GET and POST submission models, native input constraints, canvas, SVG, and multimedia integration.
Unit II CSS3 Styling, Responsive Layouts & Animation CSS3 cascading order, specificity, box model, Flexbox layout module, CSS Grid systems, z-index stacking contexts and layering, 2D and 3D transforms, transitions, keyframe animations, media queries, and mobile-first responsive design principles.
Unit III Client-Side Scripting & Modern JavaScript JavaScript ECMAScript 6+ language features, scoping rules, lexical closures, Document Object Model (DOM) traversal and event delegation, timing intervals, asynchronous programming with Promises, async/await, Fetch API, and client-side input validation.
Unit IV Server-Side Web Processing & Architecture Server-side application execution, request lifecycle processing, server superglobals ($_GET, $_POST, $_SERVER), authentication architectures, session management, secure HTTP cookies, and RESTful API design.
Unit V Web Database Integration & Application Security Relational database integration, MySQLi/PDO prepared statements, parameterized queries, SQL injection prevention, Cross-Site Scripting (XSS) defenses, password hashing, and deployment procedures.
Reference Textbooks: (1) P.J. Deitel & H.M. Deitel, Internet and World Wide Web: How to Program, Pearson. (2) Jon Duckett, HTML and CSS: Design and Build Websites, Wiley. (3) MDN Web Architecture Reference Documentation.
Course Code: CS202 Course Title: Data Structures and Algorithms (DSA) L-T-P: 3-0-2 Credits: 4 Semester: Core

CS202: Data Structures & Algorithms — Course Syllabus

Unit Core Curriculum Topics & Learning Modules
Unit I Algorithm Analysis & Asymptotic Notations Mathematical foundations of algorithmic complexity, asymptotic bounds: Big-O (O), Big-Omega (Ω), Big-Theta (Θ), space and time tradeoffs, best/average/worst-case analysis, recurrence relations, and Master Theorem.
Unit II Linear Data Structures Multi-dimensional arrays, sparse matrices, Singly, Doubly, and Circular Linked Lists, Stacks (array and pointer implementations, infix to postfix conversion, function call stack), and Queues (Circular queues, Double-Ended Queues, Priority Queues).
Unit III Hierarchical Data Structures & Search Trees Binary Trees, recursive and iterative tree traversals, Binary Search Trees (BST) search, insertion, and deletion, self-balancing search trees (AVL Trees with rotations), B-Trees, and Heap structures (Min-Heap, Max-Heap, Priority Queue implementation).
Unit IV Graph Algorithms & Network Flows Graph representations (Adjacency Matrix, Adjacency List), Breadth-First Search (BFS), Depth-First Search (DFS), topological sorting, Minimum Spanning Trees (Prim's and Kruskal's algorithms with Disjoint-Set Union), and Shortest Path algorithms (Dijkstra's, Bellman-Ford).
Unit V Searching, Sorting & Hash Tables Internal vs. external sorting, Quick Sort, Merge Sort, Heap Sort, Counting Sort, Hash functions, collision resolution mechanisms (chaining, open addressing: linear probing, quadratic probing, double hashing), and amortized analysis.
Reference Textbooks: (1) T.H. Cormen, C.E. Leiserson, R.L. Rivest, and C. Stein, Introduction to Algorithms (CLRS), MIT Press / PHI. (2) E. Horowitz, S. Sahni, and S. Anderson-Freed, Fundamentals of Data Structures in C, Silicon Press.
Course Code: CS203 Course Title: Database Management Systems (DBMS) L-T-P: 3-0-2 Credits: 4 Semester: Core

CS203: Database Management Systems — Course Syllabus

Unit Core Curriculum Topics & Learning Modules
Unit I Database System Concepts & Architecture Evolution of database management systems, File System vs. DBMS, Three-schema architecture and data independence (logical and physical), database users and administrators, data models, and DBMS classification.
Unit II Data Modeling & Relational Algebra Entity-Relationship (ER) model, weak entities, extended ER (specialization, generalization), relational data model, relational constraints (domain, key, referential integrity), and pure Relational Algebra operations (Selection, Projection, Join varieties, Division, Set operations).
Unit III Structured Query Language (SQL) Data Definition Language (DDL), Data Manipulation Language (DML), complex queries with nested subqueries, correlated subqueries, set operators, aggregate functions, GROUP BY / HAVING clauses, views, triggers, and assertions.
Unit IV Relational Database Design & Normalization Functional dependencies, closure of attributes, minimal covers, anomalies in database design, normal forms: First Normal Form (1NF), Second Normal Form (2NF), Third Normal Form (3NF), Boyce-Codd Normal Form (BCNF), lossless join decomposition, and dependency preservation.
Unit V Transaction Processing & Concurrency Control Transaction concepts, ACID properties, schedules, conflict and view serializability, concurrency control protocols: lock-based protocols (2PL, strict 2PL), timestamp-based ordering, deadlock detection and recovery, and log-based crash recovery mechanisms (WAL).
Reference Textbooks: (1) A. Silberschatz, H.F. Korth, and S. Sudarshan, Database System Concepts, McGraw-Hill. (2) R. Elmasri and S.B. Navathe, Fundamentals of Database Systems, Pearson.
